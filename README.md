# 无忧卡挽留PK赛考核排名通报

用于展示日、周、月三个统计周期的个人、小组及大组积分排名。页面为纯静态应用，支持GitHub Pages部署。

## 计分口径

- 挽留成功：每次加1分。
- 挽留失败：每次扣1分。
- 质检考核：每次扣1分。
- 小组和大组按名单人数计算人均累计分。

## 数据更新

日报数据保存在 `dist/data/report-data.json`。每增加一天数据，页面会自动生成对应日报，并按自然周、自然月累计周榜和月榜。

首次部署完成后，日常更新流程如下：

1. 将新的日报 `.xlsx` 文件放入 `待发布日报` 文件夹。
2. 双击 `更新并发布.bat`。
3. 脚本会读取工作簿的 `计分明细` 工作表，更新同日期数据并推送到 GitHub。
4. GitHub Pages 通常会在数分钟内完成网页更新。

脚本会保留窗口并显示具体错误，不会在失败时直接闪退。日报也可手动指定：

```powershell
py -3 tools/update_from_workbook.py "D:\日报\2026-09-12日报.xlsx"
```

员工姓名、班组及考核结果属于内部信息。启用公开GitHub Pages前，应先确认数据公开范围。
