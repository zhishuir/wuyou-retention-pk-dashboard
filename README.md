# 降档低签挽留考核排名通报

用于展示日、周、月三个统计周期的个人、小组及大组积分排名。页面为纯静态应用，支持GitHub Pages部署。

## 计分口径

- 挽留成功：每次加1分。
- 挽留失败：每次扣1分。
- 质检考核：每次扣1分。
- 小组和大组按名单人数计算人均累计分。

## 数据更新

日报数据保存在 `dist/data/report-data.json`。每增加一天数据，页面会自动生成对应日报，并按自然周、自然月累计周榜和月榜。

### 三列日报格式

新日报只需三列，第一行必须是下列标题，第二行开始填写姓名：

| A列 | B列 | C列 |
| --- | --- | --- |
| 成功加分 | 失败扣分 | 质检扣分 |

每出现一次姓名计一次；重复出现会自动累计。三列长度可以不同，空白单元格会被忽略。程序会按正式人员名单补齐当天没有得分或扣分的人员，再自动匹配其大组和小组。未匹配姓名会显示在“待确认班组”，且不计入小组和大组平均分。

### 日常发布

1. 将新日报按 `YYYY-MM-DD三列日报.xlsx` 命名，例如 `2026-09-14三列日报.xlsx`。
2. 把文件放入 `待发布日报` 文件夹。
3. 双击 `更新并发布.bat`。
4. 程序读取三列姓名、累计重复次数，生成PNG日报，并将网页数据和图片发布到GitHub Pages。

双击后只需等待窗口显示“日报已发布”。程序随后会自动打开“通报图片”文件夹，图片可直接发到微信群。网页通常在1—3分钟内更新，刷新页面即可查看。窗口若显示失败，请保留提示内容后重试，不要手工修改网页数据。

文件名可用完整日期（推荐），也可写成“12日数据.xlsx”；仅写日号时，程序按电脑当前年月识别。

脚本会保留窗口并显示具体错误，不会在失败时直接闪退。日报也可手动指定：

```powershell
py -3 tools/update_from_workbook.py "D:\日报\三列日报.xlsx" --date 2026-09-14
```

## 营销PK赛

网页顶部「营销PK赛」标签展示赛季累计排名（个人、小组、大组），只加分、不扣分。

### 模板与计分

- 模板文件：`营销PK赛模板.xlsx`，只有一个工作表「加分记录」，两列：

  | 姓名 | 项目 |
  | --- | --- |

- 每出现一行就按该项目固定分值加一次分；同一人同一项目可以出现多行，逐行累加。
- 日期取自文件名（如 `2026-09-22营销日报.xlsx`），按天收集，表内不需要填日期。
- 项目分值固定（只加分、不扣分）：

  | 分值 | 项目 |
  | --- | --- |
  | 1 分 | 20元20G-7天提速流量包、30元30G-7天提速流量包、9.9元权益包 |
  | 2 分 | 35元20G连续包月流量包（首月19.9元）、15元10G包月流量包 |

- 姓名须与挽留考核名单一致，程序自动匹配大组和小组；未匹配姓名归入“待确认班组”，不计入班组人均。
- 排名口径：个人按累计积分；小组、大组按人均积分（累计积分 ÷ 参赛人数）。

### 发布

1. 把填写好的模板放入 `待发布PK` 文件夹（文件名建议带日期，如 `2026-09-22营销日报.xlsx`）。
2. 双击 `更新并发布.bat`。
3. 程序按项目固定分值累计并更新网页数据，处理完成后模板文件自动移入 `待发布PK\已发布` 归档。

员工姓名、班组及考核结果属于内部信息。启用公开GitHub Pages前，应先确认数据公开范围。
